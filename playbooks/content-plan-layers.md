# Content plan：名詞解釋（流程以五步為準）

**做事順序只跟呢份：** [content-workflow.md](content-workflow.md)

```
1. 揀 product category
2. 優化 collection / brand / product    ← catalog，到呢步停
3. 搜該 category 的 queries → 歸納 bucket
4. 每個 bucket 做 keyword cluster（為文章組詞）
5. 就住 bucket 用 cluster 寫唔同角度的 Journal
```

呢份只解釋 **Category / Bucket / Cluster / Pillar** 四個詞。  
**唔好** 把下面四層當成另一套步驟編號。

---

## 四層分別（用 Gessi 浴室做一條線）

| 層 | 係咩 | 唔係咩 | COLOURLIVING 例子 |
| --- | --- | --- | --- |
| **Category** | 生意分類：舖頭賣咩、想多邊類客人 | 唔係 SEO 詞表 | 浴室龍頭（先過燈飾） |
| **Bucket** | 內容主題桶：今季文章只打呢 2–3 個方向 | 唔係 Shopify collection、唔係 blog category、唔係一篇文題 | 「邊度睇／指定歐洲龍頭」 |
| **Cluster** | 一組同一意圖的搜尋詞，用來寫 **一篇文** | 唔係把詞分配去 collection 的工單 | `where to see Gessi in Hong Kong`、`gessi 龍頭 香港` → 一篇 Journal 的詞表 |
| **Pillar** | 一篇完整答嗰個問題的 Journal | 唔係產品卡、唔係 collection 文案 | *Where to see Gessi taps in Hong Kong*，內連已優化的 `/collections/gessi` |

一句：

- Category = **賣咩**（步驟 1）  
- Bucket = **今季文章講咩主題範圍**（步驟 3）  
- Cluster = **一篇文打邊堆近義搜尋**（步驟 4）  
- Pillar = **寫出嚟的文章**（步驟 5）

Collection／品牌頁／PDP 優化 = **步驟 2**，唔屬呢四層入面的「寫文」。

同一個桶點樣拆成唔撞的幾篇：[bucket-vs-many-pillars.md](bucket-vs-many-pillars.md)。

---

## 點解要拆四層（文章策劃用）

**1. Category 先：否則內容同貨盤唔對。**  
寫「智能家居」但舖頭唔賣，Google 排到都轉唔到預約。先揀有合約、有陳列、90 日想要詢盤的類。

**2. 第 2 步先優化貨頁：否則文章落地冇貨。**  
呢點喺 [content-workflow.md](content-workflow.md)，唔喺呢份重複教點改 H1。

**3. Bucket 收窄：否則 Journal 會變成雜誌。**  
三個桶先至決定「呢 90 日 *唔寫* 乜」。Bucket 係拒絕清單，唔係 SEO 技術。

**4. Cluster 為一篇文組詞：否則十個近義詞開十篇。**  
一個 cluster = 一篇 Journal。唔好把「cluster」理解成「呢堆詞歸呢個 collection」。貨頁詞喺步驟 2 已用 [keyword-clusters.md](keyword-clusters.md)。

**5. 一篇 pillar 答一個問題：否則永遠得碎片。**  
Google／AI 要完整答案。短訊、IG、EDM 再從文章拆。

## 互相點用（唔好讀成「邊頁收詞」圖）

```
Category 浴室龍頭
  │
  ├─ 步驟 2（catalog，已完成）
  │     /collections/bathroom-faucet
  │     /collections/gessi  /dornbracht  /fantini
  │     英雄 PDP
  │
  └─ 步驟 3–5（文章）
        Bucket A「邊度睇／指定歐洲龍頭」
          └─ Cluster → Journal《Where to see Gessi in Hong Kong》
                內連 → /collections/gessi（已優化，唔再改）
        Bucket B「香港浴室點指定」
          └─ Cluster → Journal《點樣為香港浴室指定歐洲龍頭》
                內連 → /collections/bathroom-faucet
        Bucket C「到店點睇」
          └─ Cluster → Journal《灣仔浴室指定點樣行》
                內連 → About
```

- **步驟 2** 贏目錄意圖（想睇 Gessi 貨 → collection）。  
- **步驟 5** 贏問題意圖（想知點指定／點去睇 → Journal）。  
- 文章 **連去** 貨頁；寫作指南 **唔再教** 改貨頁。

典型錯法：

| 錯 | 點解衰 |
| --- | --- |
| 先開 15 個 blog category | Category／bucket 未定 |
| 講寫文時夾雜改 collection | 兩段工撈埋，永遠做唔完其中一段 |
| 一個 cluster 開十篇近義文 | 互搶 |
| 文章唔連 collection | Google 唔知文同貨盤同一間店 |
| 第 2 步未做就寫文 | 文章排到，落地貨頁仍空白 |
