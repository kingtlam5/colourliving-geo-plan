# 一個 Bucket 點解唔等於好多篇相似 Pillar

**適用時機：** 流程第 5 步（寫 Journal）。Catalog 已喺第 2 步做完。

替換測試同角度表只用來 **拆文章同文章**，唔用來叫你停寫、改 collection。第 2 步嘅頁已經優化；文內連過去即可。

龍頭例：

| | 係咩 | 唔係咩 |
| --- | --- | --- |
| Bucket A「邊度睇歐洲龍頭」 | 今季 Journal／collection 文案 **只准** 圍繞指定、陳列、香港買歐洲龍頭 | 唔係一篇叫「邊度睇歐洲龍頭」的文，更唔係 Gessi／Dornbracht／Fantini 三篇同一骨架 |
| Cluster Gessi-HK | 搜尋詞歸 `/collections/gessi` | 唔等於必須再寫一篇同 collection 差不多的 blog |
| Pillar | 只在 **collection 答唔完** 的那條問題上開文 | 例如「到灣仔點樣指定 Gessi」可以開；「Dornbracht 香港邊度買」若 80% 只換店名同 NAP → **唔開**，去改 collection |

**替換測試：** 把文裡所有 Gessi 換成 Dornbracht，其餘句子仍然成立 → 呢篇唔係第二條 pillar，係 **品牌頁範本**。品牌頁範本只用於 collection 答案段，唔開三篇 Journal。

## 點解「一個桶好似要寫好多篇」會撞車

Bucket 有意寫得闊（「邊度買」），方便拒絕燈飾／平貨。  
人腦會自動把闊桶拆成：Gessi 邊度買、Dornbracht 邊度買、Fantini 邊度買、歐洲龍頭邊度買——四條 **同一意圖**（where + 香港 + 龍頭）。答案段都會變成：灣仔洛克道、預約、只送香港。Google 同 AI 會當重複。

正確分工：

| 意圖 | 邊頁負責 | Journal？ |
| --- | --- | --- |
| Gessi 香港／目錄 | **Collection** `/collections/gessi` | 通常 **唔使** 第二篇 where-to-buy |
| Dornbracht／Fantini 同上 | **各自 collection** | 唔開 clone 文 |
| 歐洲龍頭總覽 | `/collections/bathroom-faucet` | 唔開「邊度買歐洲龍頭」再重講一次地址 |
| Collection 答唔完的問題 | **先至** 一篇 pillar | 每條問題一篇，角度必須唔同 |

所以：**品牌 where-to-buy 今季最多 1 篇**（只打你最想 AI 抄對的那一個，例如 Gessi）。其餘品牌用 collection 答案段。桶 A 的「好多 cluster」主要係 **好多正規頁**，唔係好多 blog。

## 點樣由一個桶生出「唔同」的 pillar（改角度，唔改形容詞）

每篇 pillar 要獨佔 **一條問題 + 一個讀者 + 一個承諾**。用五個軸，每次只轉 **一個** 軸（轉兩個就易寫到離題）。

| 軸 | 意思 | 龍頭例子（每格一篇，唔好合成一篇） |
| --- | --- | --- |
| **1. 意圖** | where / how / which / visit | 邊度睇 Gessi ≠ 點樣為香港浴室指定龍頭 |
| **2. 實體** | 一個品牌 vs 品類 vs 陳列室 | Gessi vs 龍頭品類 vs 灣仔浴室樓層 |
| **3. 讀者** | 屋主翻新 vs 室內設計師 | 屋主帶相片 vs ID 要 FF&E 流程 |
| **4. 限制條件** | 香港特有約束 | 細浴室出水距、入牆、潮濕同 PVD |
| **5. 決策階段** | 認舖 vs 對比 vs 落單指定 | 「係咪呢間店」vs「Gessi 定 Dornbracht」vs「到店帶咩」 |

**今季水龍頭建議只寫 3 篇 Journal**（外加各品牌 collection 文案），唔寫 10 篇：

| # | 所屬桶 | 獨佔問題（H1 方向） | 正規頁 | 故意唔寫嘅 |
| --- | --- | --- | --- | --- |
| 1 | A | Where to **see / specify Gessi** in Hong Kong（唯一品牌 where 文） | `/collections/gessi` | 唔再寫 Dornbracht／Fantini where 文 |
| 2 | B | How to specify European taps for a **Hong Kong bathroom**（呎吋、入牆、水壓） | `/collections/bathroom-faucet` | 唔重複「我哋喺灣仔賣 Gessi」當主線 |
| 3 | C | What happens in a **Wan Chai bathroom specification visit** | About | 唔重寫品牌目錄 |

若人力只夠 1 篇：只做 #1 或只做 #2（#2 對成個龍頭 category 更槓桿）。  
第 4 篇以後先考慮（仍然要通過替換測試）：

- 桶 B：PVD／面飾同香港潮濕（護理 + 點樣揀色）— **唔講** 邊度買  
- 桶 B：入牆恆溫 vs 明裝（技術決策）  
- 桶 A 例外：一篇 **對比** Gessi vs Dornbracht vs Fantini **喺同一條櫃檯點揀**（主詞係 which，唔係 where；地址只出現一次）  
- 桶 C：設計師 FF&E 龍頭（讀者軸）

## 三篇點樣「角度調開」（避免 70% 相同）

寫之前各填一句 **本文禁止重複的句子**。若兩篇答案段可以對調，就合併。

**Pillar 1（Gessi where／see）**  
- 必須獨特：Gessi 系列點樣喺舖頭睇、PVD 要睇實物、連 Gessi collection 同 1–2 隻 Gessi SKU  
- 禁止當主線：入牆教學、三個品牌評分表、設計師報價流程  
- NAP：一節到店即得  

**Pillar 2（香港點指定 — 品類）**  
- 必須獨特：香港浴室限制（窄、去水位、入牆深度、恆溫）、指定清單（帶圖則、問水壓）、連 **bathroom-faucet** 同兩個 **唔同品牌** collection  
- 禁止當主線：長段 Gessi 品牌故事、再講一次「我哋係 House of Brands」開場  
- 店名／地址：答案段各一句，之後用「到店指定」帶過，詳細 NAP 連去 About 或 Pillar 3  

**Pillar 3（到店流程）**  
- 必須獨特：預約點做、浴室樓層點行、帶咩、陳列品 vs 訂貨、同 specialist 點溝通  
- 禁止當主線：系列介紹、Gessi vs Dornbracht 對比  
- 品牌：只說「例如龍頭牆」，連 bathroom-faucet，唔開 Gessi 百科  

互相內連：**每篇最多連另外一篇 pillar 一次**，主內連仍係 collection。唔好三篇互抄同一段洛克道介紹。

可共用（每篇最多 2 句）：只送香港、建議預約、presented 用語。  
不可共用：同一答案段、同一 FAQ 四條、同一張產品相配同一段字。

## 寫題目時用呢條公式

```
Pillar 題 = 桶內的一個問題
          + 一個實體（Gessi / 品類 / 陳列室）
          + 一個香港限制或一個讀者
```

合格：`How to specify a wall-mounted mixer in a small Hong Kong bathroom`  
不合格：`Dornbracht taps in Hong Kong`（同 Gessi 篇同一公式，只換品牌）

Cluster 仍然要：Pillar 2 主詞係 `european bathroom faucets hong kong`／香港浴室指定，**唔係** 再搶 `gessi hong kong`。`gessi hong kong` 留俾 collection + 最多 Pillar 1。
