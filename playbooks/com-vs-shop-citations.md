# 對外網址：vendor 繼續寫 `.com`，唔好發動改站運動

**結論：301 做好之後，唔使（亦不應該）叫品牌商／名錄把官網改成 `colourliving.shop`。**

長期計劃係 `.com` = 品牌站、`.shop` = e-shop。而家 `.com` 暫時 301 去 `.shop`，係 **借權重俾網店**，唔係宣布 `.shop` 永遠係公司官網。

---

## 301 實際等於咩、唔等於咩

| 301 會做 | 301 **唔會**做 |
| --- | --- |
| 有人撳 `colourliving.com` → 自動去到 `.shop` | 令全世界「官網欄」在法律／品牌上變成 `.shop` |
| Google 把舊連結權重 **多數** 傳去目的地 | 令兩條域名永遠係同一個網站 |
| 舊名片、舊稿、vendor 連結 **繼續用得** | 日後你停 301、`.com` 再放品牌內容時，自動當冇事發生咁轉返 |

所以：「唔轉 vendor 又有咩影響？」——**對客人幾乎冇影響**（多一次跳轉，通常睇唔到）。對 Google，權重已經經 301 去咗 `.shop`。你付的代價只係地址列會變成 `.shop`，同搜尋結果會顯示 `.shop`（因為真正有內容嘅係網店）。

你 **唔使** 為呢啲去煩 20 個歐洲品牌的 dealer team。

---

## 點解「全部改 `.shop`」係較差做法

假設而家叫齊 Gessi / B&B / Flos / Roca 改 Where to buy = `.shop`：

1. **關係成本高。** Luxury stockist 一封信可能要品牌經理、意大利總部、亞洲 office 三層批。為一個暫時 redirect 不值得。
2. **你之後要用返 `.com` 做 branding site。** 到時又要叫佢哋改返——第二次多數會被無視，名錄永遠 `.com` / `.shop` 混雜。
3. **你把 Stage B 的後鏈預支晒。** Vendor 連去 `.com` 係將來品牌站最值錢的連結。而家改去 `.shop`，品牌站開工嗰日 `.com` 幾乎零外鏈。留住 `.com` 連結：而家 301 **借** 俾網店；將來停 301，同一批連結 **還** 俾品牌站。
4. **Where to buy 應該寫公司官網，唔係 checkout 網域。** `.shop` TLD 一看就係網店。品牌 locator 寫 `colourliving.com` 更似 House of Brands。
5. **網站欄係 NAP 最弱嗰項。** Local SEO 真正要一致的係店名、地址、電話。網址唔一致、但 301 通，傷害好細。

「301 = 永久等於 `.shop`」只係對 **而家呢個過渡期的搜尋引擎** 講。對 **公司身份** 同 **將來分拆**，`.com` 仍然係品牌域名。

## 邊個改、邊個唔改

### 唔好改（保持 `https://colourliving.com`）

- 歐洲品牌 Where to buy / stockist / dealer locator
- 媒體稿、舊新聞「官網」欄（能更正 NAP 就更正地址電話；**唔好**專登改網域）
- HKTB PartnerNet、目錄式 citation
- 名片、報價封面「Website」、公司介紹 PDF 的官網
- 電郵網域繼續 `@colourliving.com`（同網站 TLD 無關，永遠唔改）

Vendor 而家若已經寫 `.com`：**零動作。**  
若寫咗一個 **404 內頁**（舊產品路徑）：你優先喺 Shopify 加 301 map；得唔到對應先至問對方改連結——改去對應 `.shop` 產品／品牌頁，或改去 `colourliving.com` 根網址（會 301 去店）。

### 你自己控制、改一次就得、Stage B 30 秒改返

| 位置 | 階段 A（而家） | 階段 B（`.com` 品牌站 live） |
| --- | --- | --- |
| **Google Business Profile → Website** | `colourliving.com`（301 會帶去店）**或** `.shop`（見下面） | 改回 / 維持 `.com` |
| Facebook / IG / 小紅書 **簡介** | 可用 `.shop`（客人即刻知去買）或 `.com` | 簡介可改 `.com`，Shop 掣可留 `.shop` |
| 付費廣告、EDM「Shop now」 | **必須 `.shop`** | 仍然 `.shop`（checkout 永遠喺網店） |
| Shopify / Merchant Center / GA4 | `.shop` | `.shop` |
| 產品／分類深鏈 | `.shop/products/...` | 仍然 `.shop` |

GBP 你自己改，**唔使經 vendor**。兩個都可以，揀一個就唔好每季轉：

- **建議（配合將來品牌站）：GBP Website = `https://colourliving.com`。** Maps 撳「網站」→ 301 → 客人照樣入到店。Stage B 呢格已經啱。
- **可接受：GBP = `.shop`。** 地址列唔跳。品牌站開張嗰日你自己改返 GBP，仍然只係一個欄位。

**唔好**為咗 GBP 去叫 Flos 總部改 locator。

### 新 PR／新合作（階段 A）

稿件可以寫：

> Official website: https://colourliving.com  
> Shop: https://colourliving.shop

記者通常只抄一條。若只容一條，給 **`.com`**（品牌身份）。廣告落地頁先用 `.shop`。

## 「唔轉」嘅真實剩餘風險（細，而且有解）

| 風險 | 大唔大 | 點處理 |
| --- | --- | --- |
| 客人見到網址跳一次 | 細 | 301 夠快；luxury 客人多數由 WhatsApp／預約入 |
| Google 搜尋結果顯示 `.shop` | 預期行為 | 因為內容喺網店；唔係 bug |
| `.com` 內頁仍 404 | **呢個先係大** | Shopify 要 path-preserving 301，唔係叫 vendor 改 |
| AI 有時 cite `.com`、有時 cite `.shop` | 細 | 兩邊都去到同一間店；Stage B 之後 cite `.com` 更好 |
| 有人 bookmark 咗 `.shop` | 冇問題 | 網店 URL 永遠有效 |
