## Step 3 — Keyword cluster：去邊度搵、點組成、幾多個詞、點用

### Cluster 同 bucket 的關係

- **一個 bucket 下面有 2–5 個 cluster。**  
- Bucket 話「今季講邊度買歐洲龍頭」；cluster 話「Gessi 呢堆搜尋詞歸 `/collections/gessi`，Dornbracht 另一堆歸另一頁」。  
- **唔好** 一個 bucket 一個超大 keyword 袋；否則 Gessi 同「浴室龍頭」互搶。

```
Bucket A 邊度睇歐洲龍頭
  ├─ Cluster Gessi-HK     → 正規 /collections/gessi
  ├─ Cluster Dornbracht-HK → /collections/dornbracht
  └─ Cluster Fantini-HK    → /collections/fantini

Bucket B 香港點指定
  ├─ Cluster 品類龍頭      → /collections/bathroom-faucet
  └─ Cluster 入牆／恆溫     → 第二篇 pillar（連返品類頁）

Bucket C 到店
  └─ Cluster 灣仔浴室陳列   → /pages/about-us（+ 本季一篇到店文）
```

### 去邊度抄詞（組成一個 cluster 的原料）

對 **一個正規頁**（先定 URL，再收詞，順序唔好反）：

1. GSC：該頁「成效」已有的 query；再全站搜品牌名  
2. Google 自動完成：主詞 + `hong kong` / `香港` / `灣仔` / `龍頭` / `tap` / `showroom`  
3. 相關搜尋、PAA  
4. 你哋產品 title／型號（`59003.706`）— 型號歸 **PDP cluster**，唔塞入品牌 cluster  
5. GEO 題庫：[geo-monthly-prompts.md](geo-monthly-prompts.md) 浴室那組  

### 幾多個詞先叫一個好 cluster

| | 建議 |
| --- | --- |
| **主詞 1 個** | 意圖最清、最想贏，例如 `gessi hong kong` |
| **輔詞 2 個** | 近義，例如 `gessi 香港`、`gessi tap hong kong` |
| **支援 4–10 個** | 只放該頁 H2／FAQ／一句，**唔開新頁** |
| **總數 7–15 個** | 少過 5 通常未成堆；多過 20 多數混咗第二個意圖，要拆 |

**拆 cluster 的訊號：** 詞變成另一種意圖。  
`gessi hong kong`（邊度買）同 `gessi rilievo 59003`（型號）唔能同一 cluster。  
`bathroom faucet hong kong`（品類）同 `gessi hong kong`（品牌）唔能同一正規頁當主詞。

語言：品牌名英文；中文用香港繁體（龍頭、面盆龍頭）。唔使「傑西」。

### 組成方法（一張表就得）

每行一個 cluster：

`主詞 | 輔詞 | 支援詞 | 意圖 | 正規 URL | 今季動作`

動作只有三種：**fortify 現有頁**（改 H1／答案段）／**寫 pillar 支援**／**先建頁再寫**。

- Pillar 的主詞可以同 cluster 主詞 **略有分別**（問題句 vs 品牌+地區），但必須內連正規 collection，錨點用品牌名

## Step 5 — 寫 pillar 時點用 bucket／cluster（規則）

全文示範：[pillar-gessi-hong-kong.md](pillar-gessi-hong-kong.md)

| 做法 | 頻率／規格 | 原因 |
| --- | --- | --- |
| **答案段** 開頭 40–80 字答晒：邊間店、地址、可睇 Gessi、預約、只送香港 | 每篇 1 次，首屏 | GEO／AI 抄呢段；SEO 首段相關 |
| **主詞** `Gessi Hong Kong` / where to buy Gessi | H1 一次、首段一次、一個 H2、meta title 一次 | 多咗 = stuffing |
| **輔詞** 分佈在 H2／FAQ | 各 1–2 次 | 覆蓋 cluster 唔開新頁 |
| **H2 用問題句（Q&A）** | 4–7 個 | 對 PAA 同 ChatGPT；唔用「Overview 1」 |
| **可見 FAQ** 文末 4 條 | 每條答案 2–4 句，含 1 個事實 | 人同 AI 用；**唔加** FAQPage schema 去博 rich result |
| **內連** | 800–1500 字大約 **4–8 條** | 少過 3 篇同貨盤斷開；20 條似目錄 |
| **錨點** | 描述性：`Gessi collections at COLOURLIVING`、`bathroom faucets`；唔用 click here | Google／AI 讀錨點當上下文 |
| **NAP** | 全文完整地址 **1 次**；店名 3–6 次 | 同 footer 一致，唔每段重複洛克道 |
| **產品連結** | 1–3 個真實 PDP | 證明有貨；唔使連 20 隻 |
| **CTA** | 文中 1 次 + 文末 1 次 | 預約／WhatsApp |
| **長度** | 約 900–1400 字 EN（中文可另篇或文內一節） | 夠答問題；唔寫品牌百科全書 |
| **作者／日期** | 顯示 | E-E-A-T；陳列室經驗 |

**唔好：** 全篇重複 gessi hong kong 十次；宣稱 exclusive；抄 Gessi 官網長文；無地址；無連 collection。

**格式：** 答案段 → Q&A H2 → 小清單 → 內連 → FAQ → CTA。唔使編號「Bucket A」出現在客人正文。
