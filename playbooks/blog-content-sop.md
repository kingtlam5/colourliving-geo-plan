# Blog／Journal 內容 SOP（**只限流程第 5 步：寫文**）

Catalog 優化（collection／品牌／產品）係流程 **第 2 步**，用 [collection-page-sop.md](collection-page-sop.md)／[product-page-sop.md](product-page-sop.md)，**唔用呢份。**  
總順序：[content-workflow.md](content-workflow.md)。

呢份只講：brief → 寫 Journal → 發布。文章 **連去** 已經優化的貨頁。  
**唔包括** 改 collection H1、答案段、或「發布後返去改品牌頁」。

龍頭示範文：[pillar-gessi-hong-kong.md](pillar-gessi-hong-kong.md)。格式：[pillar-blog-format.md](pillar-blog-format.md)。

你而家已有 `/blogs/news`、`/blogs/edm`（幾篇舊稿）、舊 `/blogs/trends`。新內容應集中 **一個** 對外 Journal，避免三個半死 blog 互搶。

---

## 寫一篇文的順序（唔好跳）

```
1. 開／整理 1 個 Blog + 少量 tags
2. 每篇寫 Brief（關鍵字只得 1 個主 + 2 個輔）— 詞來自流程第 4 步的 cluster
3. 寫作（答案段 → H2 問題 → 內連 **已優化** 的產品／品牌頁）— [pillar-blog-format.md](pillar-blog-format.md)
4. On-page SEO + 圖 + 作者
5. 發布。文內已連 collection 就完。唔好喺呢步改 collection。
6. 每月只加 1–2 篇支柱
```

第 2 步 catalog 未完成就唔好開始呢份。

## 題目從邊來（第 3–4 步已做完）

「必連去」= 第 2 步已優化的 URL，文章 **連結** 過去，唔係喺呢步改嗰頁。

## Step 3 — 先至去 Shopify 開 Blog 結構（好少就得）

**建議：只得 1 個對外 blog。**

1. **Online Store → Blog posts → Manage blogs**  
2. 用一個叫 **Journal**（或沿用 `news` 改名顯示為 Journal）  
3. **唔好** 再開 EDM、Trends、News 三個一齊更新  
4. 舊 EDM 活動稿：留 archive，或 301 去 Journal；唔好刪到 404

**Tags（代替一堆 category）** 先定 8–10 個，之後每篇最多打 2–3 個：

`showroom` `bathroom` `furniture` `lighting` `gessi` `bb-italia` `designers` `buying-guide`

Shopify blog「分類」好弱；tags + 支柱 H1 已經夠。**唔好** 先建 15 個空 category 等內容。

## Step 4 — 每篇發布前寫 Brief（半頁紙，強制）

一篇未寫 Brief 就唔好開 Google Doc。

```
題目 H1：
主關鍵字（1個）：例 Gessi Hong Kong
輔助（最多2）：Gessi 龍頭、Gessi 香港
搜尋意圖：邊度買 / 點樣選 / 到店
目標讀者：屋主翻新 / 設計師
必答（開頭40–80字）：COLOURLIVING 係咪可以睇、地址、預約、只送香港
H2 大綱（4–6個，用問題句）：
內連：品牌 collection、2個產品、About
CTA：Book showroom / WhatsApp
唔可以講：exclusive（除非合約）、海外送貨
作者：真名 + 職位
```

H1 用問題句或長意圖，**唔好** 同第 2 步已優化的 collection H1 逐字相同。文章連去嗰頁，唔喺呢步改嗰頁。

## Step 5 — 寫作結構（每篇都一樣）

1. **開頭直接答**（人同 AI 都會抄）  
2. **事實表**：地址、時間、相關品牌、送貨香港  
3. **H2 = 客人會問的句子**  
4. **3 個產品／系列** 連去 PDP（用 `/products/handle`）  
5. **去陳列室／WhatsApp**  
6. 作者、日期、最後更新  

長度：中文約 1,000–1,800 字或英文 800–1,200 字。寧願一篇完整，唔好四篇 200 字。

舊 hospitality 2022 稿唔好當新支柱；要麼更新年份同內連，要麼 archive。

---

## Step 6 — Shopify 發布檢查

**Blog post SEO 欄：**

- Title：主意圖 + Hong Kong／香港（≤ 60 字元）  
- Description：一句答案 + 灣仔  
- URL handle：英文短橫，例如 `gessi-hong-kong`

**正文：**

- 只有一個 H1（通常係標題）  
- 圖：檔名同 alt 含品牌／品類，陳列室實拍更好  
- 內連最少 3 條去 collection／product／about  

**發布後（仍然係寫文工單，唔改貨頁）：**

- GSC URL 檢查 → 請求編入索引（只限支柱，唔好全站狂撳）

## Step 7 — 節奏

| 週 | 做 |
| --- | --- |
| 每週 | 最多 1 篇支柱（第 5 步） |
| 每月 | 對 GEO prompt 集：呢篇有冇被 AI 抄 |
| 唔做 | 每日「潮流家居 5 大趨勢」無產品、無地址；亦唔好喺寫文週夾雜改 collection |

## 常見錯

| 錯 | 改 |
| --- | --- |
| 先開 10 個 blog category | 1 個 Journal + tags |
| 先做大關鍵字表再想題 | 先 12 條支柱，關鍵字服務題目 |
| 文同品牌頁同一個 H1 | 文打問題句；貨頁 H1 已喺第 2 步定好 |
| 無內連 | 每篇最少 3 條去錢貨頁 |
| EDM 活動當 SEO | 活動放 Journal tag `event`，唔另開一個 blog 主場 |
| 寫作 SOP 裡教改 collection | Catalog 只屬第 2 步 |

**一句：** 呢份從第 5 步先開始。Category 係第 1 步；貨頁係第 2 步；query→bucket→cluster 係第 3–4 步。
